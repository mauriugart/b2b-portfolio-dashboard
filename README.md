# B2B Client Portfolio Automation 📈

## The Business Problem
Small and mid-sized businesses (SMBs) often struggle with messy CRM exports, manual financial spreadsheets, and inconsistent data entries. Tracking active client revenue and organizing portfolios manually in Excel is error-prone and consumes hours of valuable administrative time.

## The Solution
This project provides an automated ETL (Extract, Transform, Load) pipeline and an interactive web dashboard. It allows business owners to upload their raw, unformatted CSV reports and instantly get actionable insights, clean datasets, and dynamic revenue tracking—without writing a single Excel formula.

## Features
* **Automated Data Cleaning (Pandas):** Automatically strips currencies, symbols, and normalizes text/date formatting anomalies.
* **Interactive Dashboard (Streamlit):** Allows users to dynamically filter their portfolio by client status to visualize revenue at risk or lost capital.
* **Export-Ready Data:** Generates a clean, standardized dataset ready to be imported into downstream accounting or CRM software.

## Tech Stack
* Python, Pandas, Streamlit
